# Test Case: TC-CAM-001

## Test Information
- **Test Suite:** TS1-Functional
- **Test Type:** Functional
- **Priority:** High
- **Related Requirement:** REQ-CAM-001
- **Automatable:** Yes
- **Test Data Required:** Valid camera configuration JSON

## Preconditions
- Admin user is logged into the system
- System services are running (stream manager, AI inference engine, backend)
- Valid RTSP stream is available at rtsp://test-stream.example.com/live
- Database is accessible and responsive

## Test Steps
1. **Step 1:** Send POST request to `/api/v1/cameras`
   - **Request Body:**
     ```json
     {
       "name": "Production Line Camera",
       "area": "AREA-A",
       "rtsp_url": "rtsp://test-stream.example.com/live",
       "fps": 25,
       "codec": "H264",
       "resolution": "1920x1080"
     }
     ```
   - **Expected:** HTTP 201 Created
   - **Response should contain:** camera_id field

2. **Step 2:** Send GET request to `/api/v1/cameras/{camera_id}` using the ID from Step 1
   - **Expected:** HTTP 200 OK
   - **Response body should match:** the submitted configuration exactly

3. **Step 3:** Send GET request to `/api/v1/cameras` (list all cameras)
   - **Expected:** HTTP 200 OK
   - **Response should include:** the newly created camera in the list
   - **Camera status should be:** ONLINE

## Expected Result
Camera is successfully created in the system with:
- Unique camera_id generated by the system
- All submitted fields stored correctly
- Camera appears in both individual and list endpoints
- Camera status shows as ONLINE
- No errors in system logs
- RTSP credentials are not exposed in any API response

## Post Conditions
- The created camera remains in the system until explicitly deleted
- RTSP stream connection is maintained and monitored
- Camera is available for streaming and inference processing
